# Design artifacts

Phase 2 output. What is here:

| Path | What it is |
| --- | --- |
| `phase-2-brief.md` | The brief sent to Claude Design. Kept so the pass can be re-run |
| `handoff/` | Claude Design's delivery — README spec, prototype, tokens, icons |
| `phase-2-reconciliation.md` | **Read before building from the handoff.** Where it diverges from the data model, and what was struck |

`handoff/README.md` is the design spec. `handoff/tokens.css` is authoritative for
colour, type, radius and motion. `handoff/prototype/*.html` are references, not
production code — open `BabyLiana.dc.html` for the annotated doc, or
`Phone.dc.html` for the interactive phone on its own.

Q-001, Q-002, Q-007 and Q-009 are answered *as proposals*. D-007 says they close
by tapping the prototype, not by reading it.

Visual specs are what agent handoffs most often lack. A screenshot committed
here is worth several paragraphs of description in a spec.

The paper-log photographs are **not** design artifacts and live in
`.specify/memory/paper-log/`. They are Phase 0 source material.
